CryoModel ChimeraX bundle – wheel build and toolshed install

All commands in steps 1 and 4 run inside ChimeraX’s command line unless noted.

1) Clean and build the wheel

   devel clean /path/to/CRYOMODEL/chimerax-bundles/cryomodel
   devel build /path/to/CRYOMODEL/chimerax-bundles/cryomodel

2) (Optional) Sync vendored library before build

   From a host shell, from the bundle directory:
   bash scripts/sync_cryomodel_into_bundle.sh

3) Fix wheel metadata if toolshed install rejects the wheel (host terminal)

   cd /path/to/CRYOMODEL/chimerax-bundles/cryomodel
   python3 fix_wheel_metadata.py dist/cryomodel-<version>-py3-none-any.whl

   Use the actual wheel name under dist/ (version must match [project] version in pyproject.toml).
   Shortcut: python3 fix_wheel_metadata.py   (uses the first .whl in dist/)

4) Install the wheel (ChimeraX command line)

   toolshed install /path/to/CRYOMODEL/chimerax-bundles/cryomodel/dist/cryomodel-<version>-py3-none-any.whl

5) Restart ChimeraX. Tools appear under Tools → CryoModel (and commands in the command list).

Uninstall (ChimeraX command line)

   toolshed list installed
   toolshed uninstall cryomodel

   If removal is blocked by dependencies: toolshed uninstall cryomodel forceRemove true
